# Professor Poke

Last updated: 2026-10-01

Probing what Pokémon battle agents know inside, and whether they use it.

We study [Metamon](https://github.com/UT-Austin-RPL/metamon), offline-RL transformer agents for Pokémon Showdown. First questions: does the agent learn the type chart internally, and does it remember the opponent's team?

Status: early planning. No results yet.

Working rules: `AGENTS.md`. Why this project replaced an earlier one: `docs/lessons-from-rile.md`.

The name: probing = poking a model, plus Professor Oak.
